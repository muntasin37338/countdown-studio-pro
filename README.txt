COUNTDOWN STUDIO PRO — MOBILE PWA

Upload all files in this folder to the root of any HTTPS static hosting service (Netlify Drop, GitHub Pages, etc). Open the HTTPS address on your device, then use Add to Home screen / Install app. For offline access, open once while online.

A local HTML file works in your browser but cannot install as a full PWA using service workers.

Data lives in the browser/app storage of each device and is NOT automatically synchronized. Use Tools > Export backup and Import backup to transfer. Back up before uninstalling, clearing browsing data, or changing site domains.

Keep the domain and storage origin the same to preserve data across hosted updates.
